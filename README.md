## Hey, I'm Deepankar 👋

**AI/ML Engineer and Data Scientist** in Pune, India. For the last **4.5+ years** I've been building enterprise AI systems that actually reach production — not demos. My work sits where **multi-agent orchestration, knowledge graphs and retrieval** meet the unglamorous reality of Postgres, AKS and 3am pager duty.

Most of what I build is invisible to end users: agent harnesses that survive restarts, registries that don't lose writes under concurrency, retrieval that still answers correctly when the vector search confidently gets it wrong.

> **I care about:** deterministic behaviour over clever prompts · observability before optimisation · schemas that make the happy path the only path · deleting the endpoint nobody called since 2023.

**Currently:** core backend architect on the **iRUN Kernel Orchestrator** at **LTM** — an enterprise AI IT-Ops platform built on LangGraph Deep Agents, FastAPI and PostgreSQL, deployed on Azure AKS.

<details>
<summary><b>🔬 Zoom in: what building the iRUN Kernel Orchestrator actually involved</b></summary>

<br/>

- **Agent harness** — LangGraph Deep Agents coordinating dynamic domain specialists via a dependency-aware DAG planner, with zero-downtime hot-swap graph rebuilds so a domain can change without dropping a conversation
- **Registry persistence** — Postgres-backed agent / MCP / UI-widget / action / memory registries with three-tier storage, lost-update-race-free concurrent writes via `LISTEN/NOTIFY` plus polling fallback, and pending-retry self-healing across workers
- **Tool & agent federation** — MCP Gateway over a remote server fleet with per-agent binding and fingerprint-gated discovery; A2A remote-agent registry with health polling and latency/failure telemetry for cross-organisation collaboration
- **Streaming** — AG-UI over SSE with concurrent-safe state emission, re-projection and TTL sweeping
- **Human in the loop** — Postgres-persistent approvals with audit trail, timeout auto-resolution, and deterministic gated-agent serialization preventing parallel-interrupt collisions
- **Memory** — three-tier system: context compaction (~80%+ token reduction, audited), durable `tsvector` history search as a retrieval backstop, and cross-thread semantic/episodic/procedural memory via `AsyncPostgresStore` (pgvector) + `langmem`
- **Cost & safety** — reserve/settle budget ledger, LiteLLM tier fallback routing, LLM Guard safety and PII redaction, OpenTelemetry → OpenObserve
- **Delivery** — multi-worker / multi-pod-safe deployment on Azure AKS with Docker, Dapr and Azure Key Vault

</details>
